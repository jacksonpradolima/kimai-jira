# Contributing

See `CONTRIBUTING.md` in the repository root for the full guide. Summary:

1. Fork the repository and create a feature branch.
2. Run `npm ci`, `npm run lint`, `npm run typecheck` and `npm test` locally.
3. Open a pull request; CI runs the same checks automatically.
4. A maintainer reviews and merges; deployment to any real Forge installation is a separate,
   manually-triggered step and is never automatic.

You do not need access to the maintainer's production Jira site or production Forge credentials to
contribute, run tests, or validate your change locally.
